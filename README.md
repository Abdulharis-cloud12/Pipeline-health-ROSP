# Jenkins Pipeline Health Analysis

An academic mini project focused on monitoring and analyzing the health of Jenkins CI/CD pipelines using recent open-source technologies.

## Project Overview

The project integrates **Jenkins, Prometheus, and Grafana** to collect, monitor, analyze, and visualize key pipeline health metrics such as build status, failures, execution time, and resource utilization.

The entire project is designed and implemented in a **Linux-based environment**, with a core focus on exploring and utilizing modern **open-source applications** for DevOps monitoring and observability.

## Team

This project is developed by a team of **4 members** as part of an academic mini project.

## Technology Stack

- **Jenkins** — CI/CD Pipeline Automation
- **Prometheus** — Metrics Collection & Monitoring
- **Grafana** — Metrics Visualization & Dashboarding
- **Linux** — Development & Deployment Environment
- **Git & GitHub** — Version Control & Collaboration

## Objective

To develop a lightweight open-source monitoring solution that provides meaningful insights into **Jenkins Pipeline health, performance, stability, and resource utilization** through Prometheus-based metrics and Grafana dashboards.
